## Acceptance criteria

1. Document the source methodology, equations, assumptions and differences.
2. Implement audio ingestion, spectral measurements, ADS-B ingestion/type filtering,
   terrain-aware candidate search, delay/Doppler modelling, event pairing and silence
   filtering, locked multi-event scoring, refinement and reports.
3. Exercise audio-to-ranked-location runs with withheld synthetic truth, distractors,
   unknown recording start, multiple events and a known-time short recording.
4. Run suitable real recordings against their actual independent flight tracks and
   published recording-position evidence; report errors and failures without
   substituting synthetic tests for real-world validation.
5. Leave exact commands, source manifests, tests and measured results.
