# Public research site

The three Pages routes share an editorial layout on warm paper with ink text and a vermilion accent. Instrument Serif sets headings, including italic emphasis. Geist sets prose and controls. Monospace is reserved for measurements, time and commands.

The overview opens with the actual Livermore recording, an aligned spectrogram and an optional measured ridge. The field notes pair experiment conditions with outcomes, original plots and source reports. The method page connects an interactive physical model to the detection and ranking stages. The local setup appears at the end of the overview and method.

Audio starts on request. The original figures open at full size, and without scripts visitors can use the native audio player, read the static model and follow original image links. Content stays in document order at narrow widths.
